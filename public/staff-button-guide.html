What each custom control does,
where to find it, and how to use it.

Omni + Gmail + Workflow
All-in-one Tampermonkey v0.1.87
Prepared 8 October 2026

Your daily workflow

  1. Keep the all-in-one script enabled and sign in to Workflow.
  2. Work in Cin7 Omni and use the NZSO number as the order reference.
  3. Check the quote wording, products, quantities and fees before saving.
  4. Complete the HubSpot step before downloading or converting a quote.
  5. For fresh Workflow payment/dispatch information, reopen the order in Omni and refresh Workflow.
Scope

This guide covers the current custom tools, their related popup actions, and Workflow controls. Repeated Close/Cancel/Refresh controls are grouped; native Omni/Gmail controls are identified. Some controls depend on your role, document type or screen.

Common actions

Save / Upload / Send: perform the action shown; wait for its result.
Close / Cancel / x: leave the current panel; not a substitute for Save.
Refresh: reload information, not save an edit.
Delete / Remove: read the confirmation and check the selected item.
Disabled or missing: check permissions, document type and prerequisites.

Opening Help in Omni

Tampermonkey | Top of the quote or sales-order action area

Help

Opens the Living Culture staff reference in a popup over the current Omni screen.

How to use: Click Help on an Omni quote or sales order. Choose a topic from the contents. Click Close or press Escape to return to your quote or sales order.

Help is available without completing the HubSpot step.

Download PDF

Opens a printable copy of the staff guide.

How to use: Use Download PDF in the guide toolbar to open the document, then use your browser or PDF viewer to save or print it.

The online guide is the shared reference for staff.

Contents / Topic links

Jump directly to a section of the guide.

How to use: Select a screen or topic in the contents. Use Contents in the toolbar to return to the topic list.

Buttons can vary by screen, document type and staff permissions.

Search / Clear search

Find button instructions by name, task or screen.

How to use: Type in Search help to filter the instructions as you type. Use the clear icon or Contents to show all topics again.

Search includes button names, descriptions and instructions.

This guide explains everyday tasks in Omni, Gmail and Workflow. The orange Add Quote label in Gmail is a pointer to the paperclip, not a clickable button.

Omni: quote and order actions

Tampermonkey | Main coloured action row

Site Visit

Opens a new site-visit booking with details taken from the current Omni document.

How to use: Check Visit By, branch, date, time, address and products. Visit By defaults to the quote creator when a matching rep is available. Click Book Site Visit.

Creates a Workflow booking; does not convert the quote.

Quote Review / Send Review

Sends the current quote into the Workflow review queue.

How to use: Click Quote Review, check the summary, add any optional notes, then click Send Review. Wait for Review Sent or Review Updated.

This is a review request, not a HubSpot deal.

HubSpot Deal

Creates or finds the HubSpot deal for the current quote and sends its quote information.

How to use: Save the quote first. Click HubSpot Deal, complete any lead-source prompt, and wait for the result. Check the returned deal link.

The result reports deal creation and order association separately. Read the confirmation before continuing.

Download Quote

Downloads the PDF for the chosen quote template.

How to use: Complete the HubSpot step first. Click Download Quote, select Quote or Custom Quote, and wait for the PDF download.

The PDF follows the corresponding native Admin template link.

Clone Quote

Uses Copy All Items to create and automatically save a new quote.

How to use: Save changes to the original first. Click Clone Quote once. A loading indicator appears while cloning runs in the background; the saved clone opens when complete.

If cloning times out, check the quote list before trying again to avoid duplicates.

Convert to Sales Order / Convert

Converts the existing quote into a sales order.

How to use: After the HubSpot step, click Convert to Sales Order. Save unsaved changes first, then confirm with Convert. Enter confirms; Escape cancels.

This changes the document type. It is not the same as Clone Quote.

Download Invoice

Downloads the sales order PDF using Dynamic Invoice.

How to use: On a sales order, click Download Invoice and wait for the file. Check the customer, items, payments and invoice date before sharing.

It does not use Quote or Custom Quote as a fallback.

Quote-only actions can disappear on sales orders. Download and conversion controls depend on the HubSpot gate and the current document type.

Omni: quote wording and installation

Tampermonkey | Beside Delivery Instructions and below line items

Quote Memo Info

Shows the standard quote-memo wording in compact, clearly headed sections.

How to use: Open it and choose the section appropriate to the order: installation required, no installation, pre-sale, in-stock or custom-made terms.

Select the correct installation wording before relying on automatic assembly fees.

Copy (quote memo)

Copies the selected memo to the clipboard.

How to use: Click Copy under the required section, then paste it into the intended field or email.

Copy alone is not the same as filling Delivery Instructions.

Fill Delivery Instructions

Inserts the selected memo into Omni Delivery Instructions and copies it.

How to use: Click under the correct memo. Review the filled text, add ETA, dimensions or other customer-specific details, and save the Omni document.

The field expands to show more of the inserted text.

Install Fees

Opens the current installation-service price list for manual selection.

How to use: Search by service, code or price. Check the model, mounting type and size band, then click Add beside the correct fee.

Check quantity and price after insertion; save the document.

Add (installation fee)

Adds the selected assembly/installation service as a line item.

How to use: Use only when a manual fee is needed or the automatic match is unsuitable. Review the completed product line before adding another.

Automatic matching already handles supported pergolas and blinds when the memo requires installation.

Custom Comments / Copy / Fill comments

Builds product-specific comment text from the selected options.

How to use: Open Custom Comments, complete the relevant choices, then Copy or Fill comments. Check the correct line and save.

Copy is clipboard-only; Fill comments writes into the detected Omni comments field.

Pergola Guide / Clear selections

Shows the pergola modification guide and a minor-modification estimate.

How to use: Choose the applicable modification types and read the resulting estimate. Clear selections resets the guide.

This is a guide; verify the quote lines and price separately.

Automatic installation matching uses pergola model, freestanding/wall-mounted type and area (for example 4 x 3 = 12 m2), or blind width. It runs only when the quote memo requires installation.

Omni: product and stock tools

Tampermonkey | Product shortcuts above the line-item grid

Product category buttons

Open the product selector or corresponding product range.

How to use: Use Tasman, Atlantic, Baltic, Caspian, Blinds, Gas Fire Pits, Teak Sofa, Aluminium Sofa, Dining Tables, Dining Chairs, Bar Furniture, Cantilever Umbrellas, Outdoor Grills, Awnings or Patio Covers. Choose the exact product/options shown.

Check the resulting SKU and variant before adding it to the quote.

Copy SKU (Living Culture website)

Copies the SKU of the selected product variant.

How to use: Choose the model, size and colour on the product page, then click Copy SKU. Paste the code into an Omni line and complete the native product selection.

A copied SKU is not a saved quote line.

Custom Products / Add

Opens the custom-product list and inserts a selected SKU.

How to use: Search the name, SKU or notes, verify its price and description, then click Add. Check the completed line in Omni.

Save the quote after changing line items.

Refresh (Available Stock)

Rechecks stock for the quoted physical products.

How to use: Click Refresh below the line-item grid and wait for the checked-product result. Compare Quote Qty, Stock Avail and Shortfall.

Assembly/service lines are excluded. Availability does not reserve stock.

Open Products

Opens the native Omni products area for further inspection.

How to use: Use it from Available Stock when you need more detail on a SKU or branch stock.

The Available Stock panel now loads automatically; the old NZ Availability button was removed.

Foshan Warehouse / Refresh

Opens the China warehouse stock view.

How to use: Click Foshan Warehouse, inspect the stock information, and use Refresh in that view when required.

China warehouse stock is not the same as NZ available stock or a promised delivery date.

LC Containers

Opens the live container tracker.

How to use: Click LC Containers and look up the relevant shipment/container. Allow the popup if your browser blocks it.

Use this for shipment context; confirm customer ETAs before quoting them.

The automatic Available Stock table shows physical products only. Installation fees and delivery charges should not be treated as stocked products.

Omni: freight and reference sheets

Tampermonkey | Freight Costs beside freight fields; reference-sheet tools

Freight description

Choose or type a shipping or collection description.

How to use: Select a suggestion or type your own wording, then save in Omni.

Freight Costs still fills both fields. Editing changes only the description.

Freight Costs

Opens the freight calculator using detected quote products and address.

How to use: Check the detected SKUs, quantities and delivery address. Review the freight result and delivery method before using it.

An incomplete address or wrong quantity can change the result.

Refresh freight with these quantities

Recalculates the detected-product freight estimate.

How to use: Adjust the quantities shown in the freight panel, then click this button and wait for the updated result.

This is not a stock refresh.

Add another product / Remove (freight)

Changes the product list used for a manual freight estimate.

How to use: Add each relevant SKU and quantity. Remove an entry if it should not be included, then recalculate.

These controls edit the calculator list; check the actual quote separately.

Get freight manually

Calculates freight from the manually entered products and address.

How to use: Enter all products/quantities and select the correct address suggestion, then click Get freight manually.

Use this when the quote is incomplete or automatic detection needs checking.

Promo Summary

Shows current promotions and promotions beginning tomorrow.

How to use: Open the summary and use its search/filter controls. Read the dates and any Starting tomorrow label before applying an offer.

A preview of tomorrow's promotion does not make it active today.

Clearance Info / New Products

Open the relevant reference sheets for clearance and new-product information.

How to use: Open the sheet, search for the product and inspect its details. Use Refresh in the sheet if the list needs updating.

Treat these as reference information; verify price and stock in Omni.

HubSpot (shortcut)

Opens HubSpot without running the quote-to-deal creation action.

How to use: Click HubSpot when you want to search or inspect CRM records directly.

Use HubSpot Deal, not this shortcut, to run the quote integration.

Some reference tools appear only on supported screens. Do not confuse a reference-sheet value with saved stock, invoice or payment data.

Gmail: quote documents and attachments

Tampermonkey | Compose/reply toolbar, beside the paperclip

Drawings

Opens the Living Culture drawing selector.

How to use: Open a compose or reply first. Click Drawings, choose the folders/options and select the required drawing.

This tool does not send the email.

Attach to Gmail (drawing)

Downloads the selected drawing and attaches it to the current compose window.

How to use: After selecting the drawing, click Attach to Gmail. Wait for the attachment to appear before continuing.

If the attachment input is not found, click the Gmail paperclip once, cancel the file chooser if needed, then retry.

Care Guides / Attach

Lets you select and attach one or more care-guide PDFs.

How to use: Click Care Guides, tick the relevant files, then click Attach (the label may include a count). Check every attached filename.

Refresh reloads the available guide list.

Add Quote -> (orange label)

A visual hint pointing to Gmail's normal attachment paperclip.

How to use: Click the paperclip to the right of the label and select the downloaded quote/invoice PDF from your computer.

The orange label itself is not clickable.

Quote PDFs / Attach selected

Where available, opens the Omni quote-PDF selector/cache.

How to use: Click Quote PDFs, tick the intended quote PDF(s), and click Attach selected. Check the NZSO number and filename.

This is a separate quote-PDF selector, not the orange paperclip hint.

Send (native Gmail)

Sends the email after your final review.

How to use: Include the relevant NZSO number in the subject when deal matching is required. Check recipient, wording and attachments, then send.

NZSO/SFOR matching supports HubSpot attachment logging. Ordinary unrelated emails should not produce a missing-quote-number warning.

Drawings and Care Guides sit together to the left of the Add Quote hint on the same toolbar row. HubSpot attachment logging is separate from creating or associating the deal.

Omni: WeCom payment messages

Tampermonkey | Sales-order payment section, beside Add a new payment

Send as

Opens the shared staff/rep list for a payment notification.

How to use: First enter a valid payment against the correct NZSO order. Click Send as and select the staff member the message should be sent as.

Selecting a person opens a confirmation; it does not immediately send.

Staff name (Send as menu)

Builds the payment message with the selected sender details.

How to use: Choose the correct rep from the list, then inspect the order, customer, amount and payment details in the preview.

Choose the person responsible for the transaction, not an arbitrary available name.

Send to WeCom

Sends the reviewed payment message to the configured NZ Payment Notification group.

How to use: Edit the preview if necessary, then click Send to WeCom once. Wait for success before closing or retrying.

This is a real external message. It does not take payment or create a refund.

Cancel / x (payment preview)

Closes the preview without sending a payment notification.

How to use: Use Cancel or the close icon if the amount, order or selected staff member is wrong.

You can reopen Send as after correcting the details.

Save (native Omni, enhanced)

Saves the sales order; the helper fills a blank Invoice Date before saving.

How to use: Check payment entries and order details, then click Save. Verify that Invoice Date and the payment are retained after the save.

Existing invoice dates are not overwritten.

Invoice Date after successful Send as

An automatic helper action, not an additional button.

How to use: After a successful WeCom send, inspect the newly filled Invoice Date and save the sales order so it persists.

Payment status then syncs from Omni amounts, not from the act of sending WeCom.

Do not click Send to WeCom repeatedly during a slow response. Check WeCom Log and the destination group before retrying an uncertain send.

Customer Photos: albums and uploads

Omni photo controls and the Workflow Customer Photos page

Upload Photos (Omni)

Uploads customer photos and links the album to the current NZSO document.

How to use: Click Upload Photos near Created By / Processed By, choose the images and finish the upload. Wait for success, then use View Album.

Check the customer and current NZSO number before uploading.

View Album / View Albums (Omni)

Open the current linked album or the searchable album collection.

How to use: Use View Album for this order; use View Albums to find another album. Select a thumbnail to view or mark up a photo.

One album can be linked to several quotes/jobs without copying each photo.

Customer Photos / Search (Workflow)

Open the customer-album page and find an album.

How to use: Click Customer Photos, enter a customer, email or address and click Search. Choose the matching album from the left list.

Permissions may allow viewing without editing.

+ New photo album / Create album

Create a customer album.

How to use: Click + New photo album, enter the customer details and linked NZSO numbers, then click Create album.

Use an existing album when the customer already has one.

Save changes

Save album metadata and linked quote/job numbers.

How to use: Edit permitted details and the Linked numbers field, then click Save changes.

Linking an NZSO number lets related site-visit photos appear in the same album.

Upload / Open & mark up

Upload files into the selected album, or open an existing photo editor.

How to use: Choose files and an optional caption, then click Upload. Click Open & mark up on a photo to annotate it.

The album page advertises a maximum of 10 MB per image; upload errors should be checked before retrying.

Remove / Delete album / Back to Workflow

Remove a photo, delete an album where authorised, or return to the planners.

How to use: Read the confirmation carefully. Removing a shared site-visit photo removes that same photo from both views. Back to Workflow only changes screens.

Delete album is restricted. It is not the same as removing one photo.

Site-visit uploads now appear automatically in Customer Photos when the album includes that NZSO number. Refresh/reopen the album before re-uploading a file you already uploaded.

Photo editor: mark up and save

Omni and Workflow | Inside Mark up photo

Select / Move

Selects and adjusts an existing annotation.

How to use: Click Select / Move, then select a line or note. Drag an end handle to change the line, or drag its middle to move it.

Moving an annotation does not alter the original photo.

Measurement

Draws a labelled measurement line.

How to use: Click Measurement and drag between the two points. Enter the measured value and units, then confirm the label.

The tool records your supplied measurement; it does not calculate real-world dimensions from the photo.

Line

Draws a plain line annotation.

How to use: Choose Line, select a colour if needed, then drag from the start point to the end point.

Use this for highlighting edges or positions.

Text Note / Colour

Adds a written note or sets the annotation colour.

How to use: Click Text Note, choose the position and enter the note. Use the Colour swatch before drawing the next annotation.

Keep the photo readable and include units on dimension notes.

Confirm label (tick) / Cancel label (x)

Accepts or discards the text for the annotation being added.

How to use: Type the label and click the tick or submit it. Click x or press Escape to abandon that label.

Finish or cancel an open label editor before saving.

Undo / Delete selected / Clear

Remove the latest mark, a selected mark, or all current marks.

How to use: Use Undo for the last annotation; select a mark before Delete selected; use Clear only when you want to start again.

Clear applies to unsaved annotations, not to the stored original image.

Save annotated copy / Close

Save a separate annotated image, or exit the editor.

How to use: Finish your annotations, click Save annotated copy and wait for success. Confirm the new image appears in the album before closing.

The original remains. Large annotation exports are compressed to help avoid oversized-upload errors.

Closing the editor is not the same as saving. If you see an upload error, keep the editor open, check the failure and do not assume the annotated copy was saved.

Workflow: navigation and shared controls

Workflow | Top navigation and job drawers

Site Visit / Quote Review

Open the visit planner or quote-review queue.

How to use: Choose Site Visit to book/manage visits; choose Quote Review to inspect and approve/reject submitted quotes.

Changing tabs does not convert an Omni document.

Deliver / Install / Collect

Open the corresponding fulfilment planner.

How to use: Use Deliver for delivery routes, Install for installation scheduling, and Collect for customer collection jobs.

A sales order may be linked to more than one planner.

Current Jobs / Open

Find an existing job across the available current-job views.

How to use: Open Current Jobs, search the NZSO/customer and click Open beside the intended result.

This is useful before importing a job that may already exist.

More

Opens additional reporting, history and administration tools.

How to use: Click More, then choose the required log, history, roster or permitted report.

Some entries are hidden by your role or permissions.

NZSO number / Open Deliver Card / Install link

Open the linked Omni order or related planner card.

How to use: Click the NZSO number for the Omni document. Use Open Deliver Card or the Install link to inspect the related Workflow job.

Check the linked number rather than relying on a customer name alone.

Details / Notes / Photos / History / Emails

Switch the content shown inside a job drawer.

How to use: Open a job, then choose the relevant drawer tab. Upload/save actions are inside the corresponding tab.

History helps establish who changed a booking or status.

Close / x / Cancel / Refresh

Close a view, abandon an action, or reload the visible list.

How to use: Use a Save/Upload/Send action before closing when needed. Refresh reloads data; it does not save edits.

The same labels are reused in many panels; check which panel is active.

Workflow uses stored Omni snapshots. Reopen the sales order in Omni to supply fresh data, then refresh Workflow. Core planner imports and webhooks no longer supply order updates.

Workflow | Site Visit tab and individual visit cards

Book Site Visit / Clear

Create a new visit, or clear the new-visit form.

Start Checklist / Open Checklist

Start or reopen the site-visit checklist.

How to use: On the visit card, open the checklist and complete the relevant questions, measurements and notes. Finish the checklist using its save controls.

Reopen the same checklist to continue instead of creating another visit.

Print Form / Print Filled

Open a printable site-visit form or the completed form where available.

How to use: Choose the print action on the visit or related review, check the contents, then use the browser print dialog.

Refresh / Open / Delete (visit photos)

Reload the photo list, open a photo, or delete a permitted photo.

How to use: Refresh after uploading. Use Open to inspect the image. Delete only after verifying the selected file and confirmation.

Delete (site visit)

Remove the visit booking from the live planner.

How to use: Click Delete on the correct visit and confirm. Check the planner/history afterward.

Deletion now stays removed across reloads and stale browser saves.

Workflow: quote review

Workflow | Quote Review tab

Import

Attempts to import the supplied NZSO quote from stored Omni data.

How to use: Open the quote in Omni first. Enter its NZSO number in the review import area, then click Import and read the result.

An already existing review may be reported rather than duplicated.

Approved (checkbox)

Records the reviewer's approval decision.

How to use: Inspect quote details, checklist and photos before ticking Approved. Add appropriate approval notes.

Available only to authorised reviewers. Review approval and CRM order association are separate steps.

Not approved (checkbox)

Records that the quote needs correction.

How to use: Write the reason or solution in the review notes, then choose Not approved. Read any status/notification result.

Be specific about what the rep must change.

Recheck control

Requests another review after a rejected quote has been corrected.

How to use: Update the Omni quote first, then use the recheck control on the rejected review where available.

Do not mark a quote approved just to avoid the recheck process.

Photos / Start Checklist / Open Checklist / Print Filled

Open the photos and linked site-visit evidence used for review.

How to use: Use Photos to inspect the customer/site images. Open the linked checklist or print its completed content.

These controls help the decision; they do not change the quote price.

Delete / Quote Review History

Remove a permitted review card, or inspect previous review activity.

How to use: Delete only the intended non-approved review where allowed. Use More > Quote Review History to inspect earlier decisions.

Check the NZSO number before removing anything.

The Omni Quote Review button submits the request; the Workflow decision controls are where authorised staff review it.

Workflow: installation planning

Workflow | Install tab and scheduled install cards

Import / Internal / External

Import stored Omni jobs and choose the install-planning scope.

How to use: Open the sales order in Omni, enter the NZSO number and click Import if needed. Choose Internal or External to view the relevant install lane.

An existing card should be found rather than imported repeatedly.

Compressed View / Monthly View / Team + and -

Change the calendar view or open/close a team lane.

How to use: Choose the view that suits scheduling. Use the team + button to expose a lane and - to close an available lane.

Drag a job into the intended day/team, then verify its saved date and time.

Reserve Time / Select days / Reserve Time (confirm)

Blocks calendar time for non-job work or unavailable time.

How to use: Open Reserve Time, choose day(s), team, time and details, then confirm. Use the calendar arrows to change month.

Reserved time is separate from a customer install booking.

Split job / Copy

Split install work, or create a follow-up copy where that action is offered.

How to use: Use Split job when work needs separate scheduled portions. Use Copy only on cards where a follow-up copy is appropriate; inspect the resulting card.

Notes / Install Notes / Save Notes + Notify Sales

Open job notes or installation-specific notes.

How to use: Choose the required notes view, edit it, then use its Save action. Save Notes + Notify Sales also requests a sales notification.

Saving notes can send WeCom; read the action label before clicking.

Install team confirmed / Sales confirmed booking / Install completed

Track installation readiness, customer booking confirmation and completion.

How to use: Tick only after the relevant step is actually complete. Sales confirmed booking sends the configured install-team WeCom notification on a new tick.

Unticking then reticking can send another confirmation. Check WeCom Log before retrying a missing notification.

Paid / Part Paid / In Stock / Stock Onsite

Show payment, stock availability and physical onsite readiness.

How to use: Use Omni to correct payment and stock data. Inspect Stock Onsite through the linked delivery controls and confirm actual delivery where permitted.

Omni-derived values can be restored by sync; manually completed deliveries remain protected.

Installation bookings now persist across save/reload. Booking a date, confirming the customer and marking the installation completed are different steps.

Workflow | Install cards and Install More tools

Sign-off

Opens the customer completion/signature form.

Times / Team tabs

Automatic features & common questions

These behaviours do not need a separate button.

Automatic install fees

Choose a memo requiring installation. Supported pergolas match by model, mounting and area; blinds match by width. No-installation wording prevents automatic insertion. Review the resulting fee, quantity and price.

Automatic Available Stock

The table loads below Omni line items and excludes assembly/service rows. Use its Refresh control if the quote changed. NZ Availability was removed because it is no longer needed.

Omni payment and dispatch sync

Payment amounts and Fully Dispatched come from stored Omni snapshots, not Core. Part-paid is not fully paid. Invoice Date is not evidence of dispatch. Reopen the order in Omni when you need a fresh snapshot.

Quote creator and shared reps

New site-visit Visit By defaults to the matching quote creator. Staff choices use the shared rep list where integrated. Check the selected name before booking or sending.

Shared customer photos

Link the correct NZSO number to the customer album. Existing site-visit photos should then appear without another upload. Refresh/reopen the album if you do not see the file.

Missing/slow button or action

Check that Tampermonkey v0.1.87 is enabled and the page is supported. Refresh the tab. Complete any required HubSpot step and allow relevant popups. Do not repeatedly click Clone or Send while an action is busy.

Job missing, status wrong, or notification missing

Search the NZSO in Current Jobs and Deliver; include booked/delivered results. Reopen the Omni order and refresh Workflow. Check WeCom Log/history before retrying a send. Report the NZSO, screen, action and error through Help Desk.
