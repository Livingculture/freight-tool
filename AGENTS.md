# Staff Release Notes

For user-facing Omni, Tampermonkey or freight changes, prepare a concise release-note draft in the companion `Livingculture/workflow` repository's `src/lib/workflow-update-catalog.ts` using a new unique dated ID. Include the affected Tampermonkey version and any update or refresh action for users.

The Workflow Updates tab automatically includes catalog notes in its admin draft queue after deployment. Do not publish notes, replace approved entries, or change existing IDs without explicit approval. If the companion repository is unavailable, tell the user that the release-note draft still needs to be added. See that repository's `docs/workflow-updates.md` for details.
